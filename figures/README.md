# Publication figures

Figures 1–3 are the six approved, original-resolution PNG and vector PDF exports. [FIGURE_LEGENDS.md](FIGURE_LEGENDS.md) contains the complete approved captions.

[Figure_2_heatmap_data.csv](data/Figure_2_heatmap_data.csv) maps display labels B01–B24 to the verified Group-OOD block identifiers and exact homology components. Other plotted numerical results are in the [supplementary datasets](../data/supplementary/README.md).

Figure-generation scripts are not distributed in this repository. These image files are publication outputs, not a claim that plotting or upstream model workflows can be rerun from released files alone.
